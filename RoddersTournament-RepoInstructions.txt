PRIMARY FUNCTION
==================================================

When somebody visits:

https://civilizedpool.com
or
https://www.civilizedpool.com

the site should determine which Thursday tournament is currently being promoted and immediately redirect the visitor to that tournament's DigitalPool overview URL.

A tournament's promotion period begins at:

12:00:00 AM America/Los_Angeles time on the FRIDAY immediately before the tournament

and continues through:

11:59:59 PM America/Los_Angeles time on the THURSDAY of the tournament.

At exactly midnight Pacific time Friday morning, the redirect should change to the NEXT Thursday's tournament.

This must work correctly in both PST and PDT. Do NOT hardcode a UTC offset such as UTC-7 or UTC-8.

Use the IANA timezone:

America/Los_Angeles

All date decisions must be based on that timezone rather than the visitor's local timezone.

Examples:

From:
Friday August 28, 2026 at 12:00 AM Pacific
through:
Thursday September 3, 2026 at 11:59:59 PM Pacific

https://digitalpool.com/tournaments/rodders-first-thursday-8-ball-932026/overview

Then beginning:

Friday September 4, 2026 at 12:00 AM Pacific

redirect to:

https://digitalpool.com/tournaments/rodders-second-thursday-9-ball-9102026/overview

==================================================
NORMAL TOURNAMENT SCHEDULE
==================================================

Rodder's tournaments occur every Thursday.

The tournament format is based on which Thursday of the MONTH the tournament falls on.

FIRST THURSDAY:
8-Ball

URL format:
https://digitalpool.com/tournaments/rodders-first-thursday-8-ball-{DATE}/overview

SECOND THURSDAY:
9-Ball

URL format:
https://digitalpool.com/tournaments/rodders-second-thursday-9-ball-{DATE}/overview

THIRD THURSDAY:
Ladies Night

Ladies Night alternates monthly between 8-ball and 9-ball.

September 2026 = 8-ball
October 2026 = 9-ball
November 2026 = 8-ball
December 2026 = 9-ball

Continue that alternating sequence indefinitely in both future calculations and, if needed, earlier calculations.

URL format:

8-ball month:
https://digitalpool.com/tournaments/rodders-third-thursday-ladies-night-8-ball-{DATE}/overview

9-ball month:
https://digitalpool.com/tournaments/rodders-third-thursday-ladies-night-9-ball-{DATE}/overview

FOURTH THURSDAY:
8 and 9 Ball

URL format:
https://digitalpool.com/tournaments/rodders-fourth-thursday-8-and-9-ball-{DATE}/overview

FIFTH THURSDAY:
There is NO predictable tournament format or URL.

Never attempt to generate a fifth-Thursday URL.

Fifth Thursdays must be supplied through the overrides file described below.

==================================================

DigitalPool puts the tournament date at the end of the slug with:

MONTH + DAY + FOUR-DIGIT YEAR

There are NO separators and NO leading zeros.

Examples:

September 3, 2026:
932026

September 10, 2026:
9102026

October 1, 2026:
1012026

October 8, 2026:
1082026

October 15, 2026:

October 22, 2026:
10222026

October 29, 2026:
10292026

Create a dedicated helper function for generating this date slug rather than repeating the logic.

OVERRIDES FILE
==================================================

Create this file in the repo root:

tournament-overrides.json

The redirect script must check this file BEFORE using the normal recurring URL-generation rules.

Use ISO date strings as keys:

YYYY-MM-DD

For now populate it with the known fifth Thursday:

{
  "2026-10-29": {
    "url": "https://digitalpool.com/tournaments/rodders-fifth-thursday-open-10-ball-10292026/overview",
    "note": "Fifth Thursday - Open 10-Ball"
  }
}

Design the override handling so I can also use this same file later for ANY abnormal tournament date, not only fifth Thursdays.

For example, I should be able to override an otherwise normal first-through-fourth Thursday URL simply by adding that tournament date to this JSON file.

The redirect priority must therefore be:

1. Determine the applicable tournament Thursday.
2. Check tournament-overrides.json for that exact YYYY-MM-DD date.
3. If an override URL exists, use it.
4. Otherwise, if it is a first-fourth Thursday, generate the normal URL.
5. Otherwise, fail safely.

Also allow an override entry to explicitly mark a tournament as cancelled by supporting something like:

{
  "2026-12-24": {
    "cancelled": true,
    "note": "No tournament - Christmas Eve"
  }
}

If cancelled is true, do NOT redirect to DigitalPool. Show the fallback page instead with an appropriate message.
